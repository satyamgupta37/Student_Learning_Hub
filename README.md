# Student_Learning_Hub
A student learning website built using HTML, CSS, and JavaScript. It includes a signup form, programming topics table, and Apna College coding tutorial videos to support student learning.

## Project Description
The Student Learning Website is a simple educational website designed for students. It provides learning resources, coding tutorial videos, and a signup form.

## Features
- Home page with navigation menu.
- Signup form for students.
- Table displaying different programming topics.
- Embedded Apna College HTML and CSS tutorial videos.
- Simple and user-friendly design.
- Separate HTML, CSS, and JavaScript files.

## Technologies Used
- HTML – To create the structure of the website.
- CSS – To design and style the website.
- JavaScript – To add form validation and interactivity.

## Project Files
- `index.html` – Main webpage.
- `style.css` – Website styling.
- `script.js` – JavaScript functionality.

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## Learning Resources
This website includes Apna College coding tutorial videos for HTML and CSS.

## Conclusion
This project helps students access basic programming learning resources through a simple and interactive website.
